# ✍️ Ghostwriter AI v1.0
**Transform raw ideas into viral LinkedIn content instantly.**

Ghostwriter AI is a specialized SaaS platform designed for founders and creators. Built with a focus on speed, personal branding, and conversion.

## 🚀 [Live Site](https://ghostwriter-cjxxc96ta-rishivarma79s-projects.vercel.app/)

---

## ✨ Features
* **Llama 3 Powered:** High-performance AI generation via Groq API.
* **Tone Selection:** Choose between *Provocative*, *Educational*, or *Authentic*.
* **Smart Paywall:** Built-in credit system (2 free posts) with Razorpay integration.
* **Seamless Auth:** Secure login via Clerk (Google/Apple/LinkedIn).

## 🛠️ Tech Stack
* **Framework:** Next.js 16 (App Router)
* **AI:** Groq SDK
* **Authentication:** Clerk
* **Styling:** Tailwind CSS
* **Deployment:** Vercel
